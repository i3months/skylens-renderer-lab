# T15.5 추적 카메라 감쇠 검증

## 계약 요약

관제탑 추적 카메라(contracts/controlview/chase.mjs):
- **감쇠 방식:** 지수 감쇠 `a = 1 − exp(−dt/tau)`, tau 는 초 단위 시간 상수
- **위치 추적:** `p ← p + (target − p)·a` (각 성분)
- **방위 추적:** `yaw ← yaw + wrapPi(targetYaw − yaw)·a`, 최단 호로 접음
- **카메라 자세:** 감쇠된 (p, yaw) 로부터 거리·높이·시선 방향 계산
- **기본값:** tau=0.35s, dist=30m, height=10m, lookAhead=0m, fovY=0.9rad, maxDt=0.25s
- **원칙:** 목표가 주어진 것만 그림(camera() 는 목표 없으면 null)
- **첫 호출:** setTarget() 첫 호출은 감쇠 없이 즉시 그 위치로 배치

## 검증

### 감쇠 공식 검증
- 작업자가 채움: 지수 감쇠가 실제로 프레임 길이 무관인지 확인(dt 를 둘로 나눠 두 번 걸어도 한 번과 같은지)

### 기본값 검증
- 작업자가 채움: T15.0L [local] 에서 원본 towerViewer.ts 의 tau, dist, height, lookAhead, maxDt 값 확인 및 비교

### 방위 경계 검증
- 작업자가 채움: 방위 ±π 경계를 가로질러도 wrapPi 로 최단 호를 타는지 확인(−180° 근처에서 ±180° 회전 방지)

### 목표 미설정 상태
- 작업자가 채움: setTarget() 호출 전에 camera() 가 null 을 돌려주는지 확인

### 파라미터 옵션 검증
- 작업자가 채움: opts 로 기본값을 변경했을 때 실제로 카메라 동작에 반영되는지 확인(거리, 높이, tau 값 변경 시 시각적 차이)
