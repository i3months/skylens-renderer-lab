- 변이 step 을 0.25 → 0.5 로. 128 장면 훑기 [cloud] (고유 (장면, 시점) 미달 수, 괄호는 장면 수): 0.3: 13(8) / 0.4: 79(23) / 0.5: 148(28) / 0.6: 178(28) / 1.0: 224(28). 0.5 부터 잡음 장면 28 개가 전부 미달이라 장면 선택에 의존하지 않는다.
