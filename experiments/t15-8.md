# T15.8 관제탑 폴백: 2D 지도 위 표지 표시

## 목적

관제탑 화면의 3D 렌더링이 불가할 때 폴백 UI 를 표시한다. 받은 드론 위치·경로·탐지 마커를 2D 지도 위에 표시하고, 받지 않은 영역은 꾸며 채우지 않는다. 자동 맞춤, live/fallback 모드 전환, 경로 점 처리의 설계 선택을 결정 0054 에서 정했다.

## 계약 요약

계약 contracts/controlview/fallback.mjs. 구현 제품 client/tower/fallback/(validate·view·markers·paths·mode·index). 서버 렌더 불가 시 3D 층 대신 2D 지도 계산을 수행한다. 호출자가 setDrones·setDetections·setPath 로 데이터를 갱신하고, frame(size) 로 화면 좌표 목록을 받는다. 네트워크·타이머 없는 동기 계산. 지도 범위는 받은 점에서만 정한다. 기본값 minSpanM: 100 m, marginPx: 16 px 는 미측정 추정값.

## 시험 목록

계약 TOWER_FALLBACK_TEST_NAMES 에서:

1. validate: 형식 위반은 TypeError, 범위 위반은 RangeError
2. view: 맞춤은 받은 모든 점을 여백 안에 넣는다(숫자 박음)
3. view: 점이 없으면 null
4. markers: 알려진 장면의 화면 좌표(숫자 박음)
5. paths: 점 전부 순서 유지
6. mode: 처음은 live, 불 아닌 값은 TypeError
7. index: 서버 불가 모의 시 배너와 지도 목록을 낸다
8. index: 받지 않은 위치를 지어내지 않는다(보간·외삽 없음)
9. index: 검사에 실패하면 이전 상태가 그대로다
10. index: 네트워크·타이머를 쓰지 않는다
