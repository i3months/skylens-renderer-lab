# T15.2 실험 노트 — 드레이프 그리기 ([cloud])

## 구성
- 계약: 제품 `contracts/controlview/drape.mjs`(DRAPE_LAYER_API·DRAPE_MODULES·DRAPE_ALIGN_MAX_PX = 1).
- 구현: `client/tower/drape/` — unproject(화소+깊이 → ENU), sample(이중선형, mask 0 제외 재정규화), store(수준 교체·추월 건너뛰기·(tx,ty) 색인), shade(지형 음영 비율), index(조립: 지형 RenderResult 를 입력받아 사본에서 색만 교체, 타일 없는 곳은 지형 색 그대로).
- 서브에이전트: opus 5(unproject, 정합 시험 2, F-393, 보조 1)·sonnet 5·haiku 2, 승격 없음. 공유 작업 트리·소유 경로 분리로 운영 — 이 회차에서 한 공유 트리에 제품·연구 코드를 함께 두고 각각 커밋한 이유는 기록되어 있지 않다(F-404 ⑦ 지적). 반려 뒤 재작업은 하위 작업마다 격리 작업 트리(feat/t15-2--N)에서 했다.

## 측정(합성, 기준 1 px 는 바꾸지 않음)
- 연직 평지: 160×90 정합 오차 0.0011 px(출력값이며 단언은 ≤ 1 px 뿐), 640×360 0.0003 px(기본 음영). 음성(0.5 m·2 m 이동 타일)은 1.25 px·5 px 로 잡힘.
- 비스듬한 8시점 × 시드 1~6(기복 지형): 정상 타일 정합 최대 0.0899 px(출력값이며 단언은 ≤ 1 px 뿐). 화면 1.5 px 어긋남은 모든 시점에서 1 px 초과로 잡힘.
- 음성 시험의 '1.5 화소'는 화면 화소로 해석(영상 화소 1.5 는 먼 시점에서 1 px 미만이라 판별력이 없음). 영상 화소 어긋남은 δ 복원 0.75 m 로 별도 확인. errPx 는 묶음 이동 보정 뒤 RMS 이며, EDGE_MARGIN_M·FOLD_MARGIN_M 제외 구역(값은 제품 client/tower/drape/align_*.test.mjs 에서 확인)에서 제외.
- 영상 밖·미도착 타일 구역은 지형 색 그대로(메우지 않음).

## renderer_basis 에서 벗어난 점
- (i) F-402 새 동작: 표본점이 속한 화소의 mask 가 0 이면 지형 색 그대로, 가중 재정규화는 mask>0 이웃에만 적용. 규칙 기록은 decisions/0044 §5·0046 T15.1c 에서 LOD 오차 상한 근거 변경과 함께.
- (ii) 위성 색에 지형 음영 비율을 곱하기: 위성 영상에는 조명 정보가 없어 지형 법선 음영을 곱해 입체감을 보존. renderer_basis 에 없는 선택이며, 결정 0046 '대가' 절에 계약·계산식 함께 기록됨.

## 반려 뒤 재작업 (PR #73 검토 #1: F-402·F-403·F-404)

- 서브에이전트 10(opus 3·sonnet 6·haiku 1), 승격 없음. 하위 작업마다 격리 작업 트리(feat/t15-2--N, 푸시 안 함)에서 일하고 작업자가 병합했다.
- F-402(높음): 표본점이 속한 화소 칸의 mask 가 0 이면 null. 칸의 mask>0 이면 mask>0 이웃만 가중해 재정규화한 이중선형. mask 1..254 는 255 와 같은 색 가중(k·mask/255 는 쓰지 않음, F-404 ①). 시험 mask_zero.test.mjs: 8×8 타일 (3,3) 칸 안 400 표본 모두 null·칸 밖 [200,200,200], 4×4 mask 0 열 안 3점 null, layer.apply 에서 mask 0 칸 화면 화소 64개가 지형 색 바이트 동일·나머지 4032개 위성 색, 옛 규칙 흉내가 400 표본 전부 null 이 아님(변이가 잡힘).
- F-403 ①: store.accept 인덱스 순회(빈 칸 TypeError, 상태 불변; forEach 변이에서 11/12 통과·1 실패). ②③: apply 가 프레임당 1회 terrain 길이·baseRgb 를 검증하고(타일 유무 무관 RangeError), NaN·Infinity 깊이 화소는 건너뜀. 화소 루프는 할당 없는 내부 경로(prepareUnproject·sampleDrapePrepared·음영 표), 직전 타일 캐시. depth·index 는 terrain 배열을 공유. 같은 입력 color 바이트 동일(느린 참조와 비교, 카메라 5종). 벤치 1280×720 전 화소 적중: 참조 520~535 ms, 새 경로 70 ms, 비율 0.130~0.136(1/7.3~1/7.7, 기준 1/5 이하). 실기기 fps 는 T15.9/T17 [local]. 의도하지 않은 동작 변화: terrain.color 가 Uint8Array 가 아니면 RangeError, shade 를 끈 층도 baseRgb 범위(0..255) 검사.
