# 실험 노트: T07 lod

## 가설
거리 제곱 근거(Δd≈d²/(f·b))에서 유도한 화면 공간 오차 기준 격자 LOD 가, 새 점을 만들지 않고도 고정 시점에서 원본 대비 SSIM ≥ 0.95 를 유지하며 점 수를 줄인다.

## 방법
제품 feat/lod. 계약 contracts/lod → 하위 작업 병렬 구현 → 작업자 통합(server/lod/hierarchy 는 작업자가 직접 작성). 참조 래스터라이저(T06)로 원본·LOD 렌더를 비교.
이번 실행의 서브에이전트: haiku 2(F2, 10) · sonnet 7(F, F3, 1, 2, 6, 7, 11, 9 중 — F·F3·1·2·6·7·9·11 = 8) · opus 5(3, 8, 4, 5, 4b). 승격 없음. F 가 지시 범위를 좁게 읽어 F3 를 추가로 띄웠다(재작업 1회).

## 실제 skylens 체크아웃으로의 시험
이 환경에는 실제 skylens 점군/체크아웃이 없다. 합성 장면(flat_boxes, terrain, holes)만 사용했다. 실데이터 SSIM·§3-6 순위표는 미확인([local]).

## renderer_basis 에서 벗어난 점
- §3-5 의 "공유 점 분포 가산" 항은 계약에 없어 넣지 않음(T07.8).
- §3-7 표 재현에 f=755 px 사용(문서 fx 754.32 와 다름).

## 남은 문제
- 거친 단계 SSIM 검증은 보강 시험 결과(아래 갱신)에 의존. 
- 칸이 두 리프에 걸칠 때 경계 점 누락/중복(한 칸 이내).
- 전체 npm test 는 부하 시 간헐 실패 1건(asset fuzz, bench/baseline SIGTERM)이 서브에이전트 보고에 있었으나 단독·재실행은 통과.
