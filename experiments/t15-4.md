# T15.4 — 방향키 조향·Q/E 고도 로컬 처리

제품 feat/t15-4, 연구 experiment/t15-4. 모델: opus 1(카메라 변환)·sonnet 3·haiku 1 + 통합 시험 sonnet 1, 승격 없음. 격리 worktree 가 연구 저장소로 만들어지는 문제로 제품 worktree 를 직접 만들어 재지시했다(서브에이전트 6개 재지시).

## 계약 (contracts/controlview/input.mjs)
키: ArrowLeft/Right 방위, ArrowUp/Down 앞·뒤, KeyE/KeyQ 고도 ±. 방위 yaw 0 = 북, 시계 방향(동) +. 앞 = (sin yaw, cos yaw, 0). 기본값 yawRate 1.0 rad/s, 속도 10 m/s, 고도 5 m/s, 고도 [1, 500] m, pitch −0.3 rad, fovY 0.9 rad, dt 상한 0.25 s. **원본 키 배치·속도는 [local] T15.0L 대조 전까지 추정**(origin 'estimated').
이 층은 네트워크·타이머·await 를 쓰지 않는다 → 입력→카메라 갱신이 같은 동기 호출 안(결정 0001, 경로 B 의 조작감).

## 모듈
state(자세 적분, step 은 갱신된 pose 를 돌려줌 — 통합에서 계약에 맞게 고침), keys(눌림 추적, 반복·미지 키 무시), camera(pose → CameraPose, quat = qz(−yaw)⊗qx(pitch−π/2), w ≥ 0), index(조립).
