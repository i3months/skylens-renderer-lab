# T16.15 — PR #95 검토 #1 잔여 정리 (F-538~F-542)

## 가설
실서버 로그(T16.12)가 들어가는 입구(runScenario 의 events 주입)를 먼저 검증해 두면, 누락·중복·잘못된 값이 위반 없이 통과하거나 스택으로 죽는 일이 없다. SPEC 수치(3 s 등)는 바꾸지 않는다.

## 방법
서브에이전트 9개(opus 1·sonnet 6·haiku 2, 승격 0)가 겹치지 않는 경로에서 병렬 구현, 작업자가 feat/t16-15 에 병합·검증. 하위 작업 브랜치는 feat/t16-15--n(로컬 전용).

## 검증
각 하위 작업이 변이(조건 삭제·floor 복원·push 전개 복원 등)를 일부러 넣어 시험이 실패함을 확인. 통합 시험 결과는 PR 본문. 실제 skylens 체크아웃·실서버 입력은 [local].
