# F-117 — T08.2 뒷면 제거 SSIM 기준 미달과 todo 분리

- 날짜: 2026-10-03
- 대상: 제품 `server/cull/backface/index.mjs`, `server/cull/backface/backface.test.mjs` (기준 브랜치 feat/culling, cde1f8c 위)
- 결론: 고칠 것 ①·② 로 해결. 24 시점 모두 SSIM 하락 0(≤ 0.002)을 todo 없이 단언하고 통과. ③(기준 정의 변경 제안)은 필요 없었으나, 아래 '남는 문제' 에 감독 판단용 메모를 둔다.

## 1. 원인 확인

참조 래스터(`renderPoints`)는 법선을 쓰지 않고 화면 정렬 원판(반경 r = fx·s/(2d))을 깊이 버퍼로 그린다. 그래서 '등진 점' 도 다음 두 경로로 최종 영상에 남는다.

- (a) 앞면 표본 사이 틈으로 비침.
- (b) 실루엣 바깥으로 원판 반경 r 만큼 번진 띠. 예: low_close_box(눈높이 3 m)에서 지붕(법선 +y, 카메라보다 위)은 전부 등지지만, 지붕 앞 가장자리 점의 원판이 벽 윗변 위로 r 만큼 튀어나와 그려진다.

순수 법선 판정(1단계)은 이 점들의 리프를 버리므로 영상이 바뀐다. 판정식 자체(원뿔·볼록 함수 최댓값)는 맞고, 점 단위 불변식(제거 리프에 앞면 점 0)도 24 시점 전부 성립한다(이번에 todo 없이 단언해 확인).

## 2. 각도 여유로는 안 되는 이유(측정)

원판 번짐에서 유도되는 각 여유는 δ = asin((s/2)/d) 다(구 원판의 접선 원뿔 반각: 이만큼 등진 면까지 원판 일부가 카메라 쪽으로 보인다). s = 0.75 m, 이 장면들의 리프 거리 d ≳ 11 m 에서 δ < 2°. 그런데 기준을 맞추는 데 필요한 여유를 일괄 각도로 훑어 보면(flat_boxes, `marginDeg` 일괄, 덮임 판정 끔):

|---|---|---|---|---|---|---|---|---|---|
| low_close_box | 1.55e-2 (10) | 1.55e-2 (10) | 8.63e-3 (8) | 8.63e-3 (8) | 8.63e-3 (8) | 4.70e-3 (5) | 0 (1) | 0 (1) | 0 (0) |
| tower_mid | 3.70e-3 (8) | 3.70e-3 (8) | 3.28e-3 (7) | 2.93e-3 (5) | 2.76e-3 (4) | 2.37e-3 (3) | 5.25e-4 (2) | 5.25e-4 (1) | 5.25e-4 (1) |
| aerial_oblique_ne | 1.99e-3 (6) | 1.99e-3 (6) | 1.99e-3 (6) | 9.21e-4 (4) | 8.42e-4 (3) | 6.71e-4 (2) | 6.71e-4 (2) | 6.71e-4 (2) | 0 (0) |

(칸 = SSIM 하락, 괄호 = 제거 리프 수.) 약 30° 가 필요하고 이는 어떤 식에서도 유도되지 않는 사후 상수다. 원인 (b) 는 등진 '각도' 가 아니라 실루엣 '위치' 에서 생기기 때문이다(지붕은 90°+40° 가량 등져도 앞 가장자리 띠가 보인다). 그래서 각도 여유 방식은 버렸다(`DEFAULT_MARGIN_DEG` 는 0 그대로, 선택 인자로만 남김).

## 3. 해결: 2단계 '확실히 덮임' 판정(occlusion 재사용)

`backfaceCull(h, camera, cones, opts)` 는 이제 두 단계다.

1. 1단계(기존): 법선 원뿔로 '리프 상자 안 어느 점에서도 모든 법선이 등짐' 이 확실한 리프 = 후보.
2. 2단계(신규, 기본 켬): 후보가 아닌 리프(앞면·혼합 리프)의 단계 0 점 전부를 가림막으로, 렌더와 같은 점 지름 s 로 `buildDepthPyramid`(server/cull/occlusion)를 만들고, `occlusionCull` 이 '가려짐' 으로 판정한 후보만 버린다.

유도(새 상수 없음):

- 피라미드 블록 값 = 블록의 모든 픽셀 중심이 원판 안에 드는(블록 반대각만큼 줄인 원판) 가림막 점 깊이 fround(d) 의 최솟값. 칸 값 V = 칸 안 블록 값 최댓값 → 칸의 모든 픽셀의 참조 래스터 최종 깊이 ≤ V.
- 후보 리프는 꼭 맞는 상자의 최소 깊이 zmin 이, 상자 투영 사각형을 원판 반경 상한 rmax = fx·s/(2·zmin) + 1 px 만큼 넓힌 영역의 모든 칸에서 zmin > V·(1+1e-6)+1e-6 일 때만 버린다. 리프의 모든 점 원판은 그 영역 안에 있다.
- 따라서 버린 리프의 점은 참조 래스터 어느 픽셀에서도 엄격히 더 멀어 이기지 못한다(동률은 먼저 온 점이 이김, 엄격 <). 각 픽셀의 승자는 남긴 점이고, 진 점을 빼도 승자가 바뀌지 않으므로 '버린 리프를 뺀 렌더 = 원본 전체 렌더'(픽셀 단위 동일) → SSIM 하락 = 0. 조건: 덮임 판정의 점 지름 = 렌더 점 지름.
- 쓰인 여유(줄인 원판, rmax+1 px, REL/ABS 1e-6, 피라미드 64)는 모두 occlusion 모듈의 기존 식·기본값이다.

인자: `opts.pointSizeM`(기본 0.05 = renderPoints 기본, occlusion 의 `DEFAULT_POINT_SIZE_M`), `opts.requireCover`(기본 true; false 면 1단계만 — 기하 성질 시험·비교용), `opts.marginDeg`(기존). 후보가 없으면 피라미드를 만들지 않는다.

## 4. 시험 구조 변경(①)

- 시점마다 시험을 둘로 나눔, todo 0 개:
  - 불변식: 1단계 제거 리프의 점은 전부 n·v < 0, 앞면으로 그려진 점의 리프는 1단계에서도 제거 0, 기본 마스크 제거 ⊆ 1단계 후보, 기본 마스크로 제거된 리프의 점은 참조 래스터에 한 점도 그려지지 않음(거짓 제거 0 의 강한 꼴).
  - 완료 기준: 기본 마스크의 SSIM 하락 ≤ `BACKFACE_MAX_SSIM_DROP`(0.002, 수정 없음).
- `KNOWN_SSIM_MISS`(todo 2건)와 buildings 의 `underside` 예외 3 시점 삭제 → 24 시점 전부 SSIM 단언(문턱은 올리기만 함).
- buildings 저시점 제거율 하한(≥ 10)과 terrain 지표 아래 제거 ≥ 100 은 1단계(`requireCover:false`)에 단언(법선 판정이 실제로 일하는지 보는 용도).
- 2단계 단위 시험 추가: 등진 평면 둘 + 카메라 쪽 법선 판. 판이 없으면 제거 0, 있으면 제거 > 0, 제거 리프의 점은 그려지지 않음.
- 입력 오류 시험에 pointSizeM(0, NaN)·requireCover(비 boolean) 추가.
- 변이 확인: 기본값을 `requireCover:false` 로 바꾸면 19 개 시험이 실패(SSIM 5건 포함) — 새 시험이 회귀를 잡는다.

## 6. 남는 문제(감독 판단용 메모, 상태: 정보)

- 2단계를 켠 뒷면 제거는 같은 점 지름의 occlusion 단계(가림막 = 모든 리프) 제거의 부분집합이다. 24 시점 실측: 뒷면 단독 제거(occlusion 이 안 버리는 것) 0 개. occlusion 제거 수: terrain street_level 39·low_close_box 50·edge_far 12, flat_boxes low_close_box 5, 나머지 0. 즉 지금 참조(법선을 쓰지 않는 래스터)에 대해서는 '영상이 안 바뀌는 뒷면 제거' 가 곧 가림 제거이고, 결합 경로에서 backface 단계의 독립적 기여는 0 이다(계산 비용만 든다: 후보가 있을 때 피라미드 1회).
- 이것은 기준 정의에서 온 구조적 결과다. 법선 컬링이 독립적 가치를 가지려면 완료 기준을 '법선을 쓰는 참조 래스터(등진 점은 그리지 않음 또는 주변광만) 대비 SSIM' 으로 바꿔야 한다. 그 경우 1단계만으로 (b) 띠·(a) 틈의 점이 참조에서도 사라져 하락이 0 에 가까워질 것으로 예상하나 측정하지 않았다. 기준 수치·정의는 작업자가 바꾸지 않았으며, 필요하면 감독이 결정 0023 에 '제안' 으로 올릴지 판단한다.
- 대안(측정 안 함): 2단계 가림막을 '모든 리프' 로 넓히면(후보끼리도 가림막) 제거가 occlusion 과 같아진다. 증명은 같으나(가림막은 원본의 임의 부분집합이면 됨) 뒷면 단계의 의미가 더 흐려져 '앞면·혼합 리프만' 으로 두었다.
