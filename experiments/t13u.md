## F-593 근접 중복 솎기
수락 0 패스에서 남은 점마다 가장 가까운 수락점 거리를 구해 최댓값 d* 바로 아래로 반경을 내린다(rCur = min(rCur·shrink, d*·(1−1e-9))). 첫 패스 재시도는 수락이 2·target 을 넘으면 중단하고 비율로 어림한다. 칸 표 확장 2배, select 뒤 표 해제. MAX_SHRINK = 0.99, 넘으면 RangeError. stats 에 zeroPasses 추가.

| 입력 | 원본 | 수정 후 |
|---|---|---|
| 400×400 평면 + 3 µm 사본 32만 점 select(200000) | 5.8~6.2 s, 수락 0 패스 82 | 1.0~1.2 s, 4(격자 몫 3 + 사본 1) |
| 250만 점 체적 13% 첫 select | 12.0 s | 4.4 s |
| 250만 점 k=50% 상주 | +242 MB(97 B/점) | +98 MB(39 B/점) |
| shrink 0.999999 | 70 s 안에 끝나지 않음 | 즉시 RangeError |

해석 두 가지(감독 확인 요청): (1) '수락 0 패스 ≤ 1회' 는 사본 때문에 생기는 것 ≤ 1 로 읽었다 — 1 cm 격자 평면은 사본이 없어도 격자 거리 사이에서 수락 0 패스 3회가 생긴다. 총 1회 이하를 요구하면 모든 패스 비용이 약 2배다. (2) '시간 2배 이내' 는 사본 없는 같은 점 수(400×800) 평면과 비교했다(0.7~0.85배). 400×400 과 비교하면 1.75~2.0배다. 체적 입력의 첫 반경 열은 원본과 달라질 수 있다.
