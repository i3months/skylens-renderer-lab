# 0008 제품 PR 은 merge commit 으로 병합

- 상태: 승인
- 날짜: 2026-10-02
- 결정한 사람: 사람
- 관련: ops/SUPERVISOR.md 병합 절

## 맥락
T01(PR #2)이 squash 로 병합돼 작업 브랜치 커밋 89개가 main 에 하나로 들어갔다. GitHub 기여 그래프는 기본 브랜치 커밋만 센다.

## 결정
기본은 merge commit. 작업 브랜치 커밋 메시지에 생성 도구 흔적이 하나라도 있을 때만 예외로 squash 하고, 예외를 감독 기록에 남긴다.

## 근거
- 커밋 이력을 main 에 남기고 기여 그래프에 반영하려는 사람의 선택.
- 커밋 메시지는 .githooks 가 막고 있어 흔적이 들어갈 일이 드물다(2026-10-02 두 저장소 전 브랜치 점검 0건).

## 대가
서브에이전트 조각을 합친 'Merge feat/<이름>--N' 같은 중간 커밋도 main 이력에 섞인다.

## 다시 볼 조건
main 이력이 읽기 어려울 만큼 시끄러워지면 rebase 병합이나 조각 병합 커밋 정리를 검토한다.
