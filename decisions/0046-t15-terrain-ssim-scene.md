# 0046 T15.1 지형 SSIM 시험 장면: 높이 잡음 0

- 상태: 제안
- 날짜: 2026-10-05
- 결정한 사람: 작업자(제안)
- 관련: TASKS T15.1, experiments/t15-1b.md, 제품 client/tower/terrain/ssim_views.test.mjs

## 맥락
T15.1 완료 기준은 '8시점 SSIM ≥ 0.95'(SPEC). 기준 영상은 같은 DEM 의 LOD 0 메시를 독립 광선-삼각형 교차로 그린 것이고, 시험 대상은 LOD 1~3 타일을 층의 CPU 래스터로 그린 것이다. 둘 다 삼각형 단위 평면 램버트 음영이다.

## 선택지
| 선택지 | 장점 | 단점 | 근거 |
|---|---|---|---|
| A 높이 잡음 0 의 부드러운 언덕 장면 | LOD 오차 상한 안에서 SSIM 이 의미를 가진다 | 실제 DEM 의 미세 질감을 시험하지 않는다 | 아래 측정 |
| B 잡음 ±0.15 m 장면, 기준 0.95 유지 | 거친 지형 | LOD 1~3 전부 미달(0.877~0.950), 시험이 항상 실패 | 아래 측정 |
| C 기준 수치를 낮춤 | 통과 | SPEC 수치를 사후에 낮추는 것 — 금지 | — |
| D 정점 법선 보간(고라우 음영) | 면 질감 감소 | 래스터에 화소별 보간이 필요, 기준 영상도 같은 모델이어야 함, 이번 회차 범위 밖 | 미시행 |

## 결정
8시점 SSIM 시험은 높이 잡음 0 장면(A)으로 0.95 를 단언한다. 잡음 장면(B) 결과는 기록만 하고 기준을 낮추지 않는다. 미해결 한계로 남긴다.

## 근거
측정(합성 DEM 시드 1, 진폭 10 m, 셀 2 m, 4×4 타일, 160×90, 8시점):
- 잡음 0: LOD 0 1.0000(전 시점), LOD 1 0.9977~0.9992, LOD 2 0.9938~0.9972, LOD 3 0.9850~0.9941. 빈/채움 불일치 0.
- 잡음 ±0.15 m(진폭의 1.5 %): LOD 1 0.8829~0.9504, LOD 2 0.8772~0.9476, LOD 3 0.8763~0.9456(서브에이전트 보고, 작업자는 잡음 0 쪽만 직접 재현).
- 원인(작업자 추정, 잡음 0 으로 SSIM 이 회복되는 것으로 뒷받침): 잡음이 LOD 높이 오차 상한(0.5 m) 안이라 단순화가 지우고, 면 단위 음영은 그 질감을 SSIM 에 크게 반영한다.

## 대가
높이 오차 상한만으로는 SSIM 0.95 가 보장되지 않는다(질감이 있는 DEM). 실제 DEM 에서의 8시점 SSIM 은 [local] 입력 없이는 모른다.

## 다시 볼 조건
실제 DEM(T14L)으로 8시점 SSIM 이 0.95 미만이면, 선택지 D(법선 보간)를 구현하고 기준 영상도 같은 음영 모델로 바꾼다.
