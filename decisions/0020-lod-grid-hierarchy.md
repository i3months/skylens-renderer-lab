# 0020 LOD 규약: 2배 격자 단계, 화면 공간 오차 기준 거리표, 입력 점 부분집합만 사용

- 상태: 승인
- 날짜: 2026-10-03
- 결정한 사람: 작업자(제안)
- 관련: T07.0~T07.11, F-092~F-095, renderer_basis §3·§3-7, 실험 노트 experiments/lod.md

## 맥락
T07 은 원본 점군(format 1, 27 B)을 거리별로 줄이는 LOD 를 만든다. RULES §1.2 에 따라 줄이는 쪽으로만 쓰고 새 점을 만들지 않는다.

## 선택지
| 항목 | 선택지 | 비고 |
|---|---|---|
| 단계 간격 | (가) 칸 한 변 edge0M·2^l / (나) 점 수 절반씩 | (가). 면 위 점 밀도가 단계마다 약 1/4. 화면 오차와 직접 연결 |
| 단계 선택 | (가) 화면 공간 오차 f·edge/d ≤ τ / (나) 고정 거리 구간 | (가). 해상도(f)를 따라간다. maxDistanceM(l)=f·edgeM(l)/τ 는 단계 l 이 쓰이기 시작하는 거리 |
| 대표점 | (가) 칸 중심에 가장 가까운 입력 점 / (나) 평균 위치 | (가). 새 점 생성 0(RULES §1.2). 법선·색만 평균(대표값) |
| 깊이 해상도 | Δd = d²/(f·b) 를 edge0M 하한의 근거로만 사용 | renderer_basis §3-7 표를 f=755 px 로 재현(문서 fx 754.32 는 첫 행 2.62 로 표의 2.61 과 어긋남, T07.3) |
| 법선 길이 0 | (0,0,0) 유지, 셰이딩 생략 | F-093 ② |

## 결정
위 표의 (가) 선택.

## 근거
- 실험 노트 experiments/lod.md 의 측정표(각 하위 작업 시험 수치).
- 한계: T07.4 의 고정 시점 8곳 SSIM 시험은 flat_boxes 200 m 장면에서 모든 리프가 단계 0 이라 거친 단계를 검증하지 못했다. 거친 단계 검증은 보강 시험(select_coarse)과 노트의 결과를 본다.
- T07.8 이웃 시점 점수는 renderer_basis §3-6 실데이터 순위표를 재현하지 못했다(실데이터 부재). §3-3 표와 §3-7 의 순서(8.26>4.14>1.04)는 재현했으나 합성 기하에서 15.37 m 가 2위로 나온다(실데이터는 공유 점 감소로 4.14 m 보다 낮음).

## 대가
