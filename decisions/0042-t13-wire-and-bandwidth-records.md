## 맥락
T13 에서 ws 서버 진입점에 배선 모듈 `server/ws/wire`(createWire)를 두었다. 0040 은 정지 알림을 호출자에게 주고 호출자가 store.close 를 부르는 방식(A)을 채택하고, 접속 계층이 직접 부르는 방식(C)을 기각했다. 이번에 감독 지시로 진입점 배선에서 정지 때 store.close 를 부르게 했다.

## 1. wire 층의 정지 처리

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 호출자 onStopped 안에서 store.close(0040 원안) 하고 wire 는 store 프록시로 실제 close 호출을 센다 | 0040 과 같다. 호출자가 정책을 쥔다 | 호출자가 close 를 빠뜨리면 TTL 재접속 반복. 계측은 프록시가 필요 |
| B. wire 가 정지 알림마다 store.close 를 직접 부른다(채택) | 진입점에서는 빠뜨릴 수 없다. 호출자 구멍이 닫힌다 | 0040 이 기각한 C 와 같다. 호출자가 정지 때 다른 처리를 하려는 경우 close 가 먼저/나중인지 고정된다. 비동기 onStopped 는 기다리지 않아 점검 중에 세션이 지워질 수 있다(0040 C 의 대가 그대로) |

채택 B. 계측은 두 카운터가 한 함수에서 늘어 항상 같던 것을 버리고 {stoppedCalls, storeCloseOk, storeCloseFailed, onStoppedErrors, sameSidStops, maxSameSidStops, sameSidThresholdHit} 로 바꿨다. close 가 던지거나 거부하면 storeCloseOk < stoppedCalls 가 된다(시험). 같은 sid 정지가 다시 오면 close 가 실패했거나 성공이라 답하고 세션을 지우지 못한 것이라 이상 신호다(sameSidStopThreshold 는 1 이상 안전 정수, 기본 3).
대가: 호출자가 onStopped 에서 하려던 정리가 close 와 순서가 꼬일 수 있다.
다시 볼 조건: 진입점 main 조립 때 호출자가 정지 때 close 전에 해야 할 일이 생기면 A 로 돌린다. 운영에서 sameSidThresholdHit 가 참이면 저장소 close 구현을 본다.

## 2. F-287 ⑦ 구조 시험으로 대체
'미결 N 을 남긴 채 새 창만 끝나는' 흐름은 순번이 오름차순인 어댑터에서는 만들 수 없다(LA 가 창 끝 이하를 전부 지운다). 억지로 만들면 앞쪽 끼어들기 splice 가 O(N)이다(N=60000 에서 86 µs/LA, 비는 약 100).

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. '< 2 비' 단언을 억지 입력으로 유지 | 원 확인 기준 그대로 | 실제 어댑터가 만들지 않는 입력이라 단언이 의미 없고 O(N) 비용을 시험이 만든다 |
| B. 구조 시험으로 대체(채택): 미결 N=2000 이 지워지지 않고 live=N, length ≤ 2·live+1024, 미결 재시도 통과·끝난 창 재시도 거부 | 어댑터가 실제로 지키는 불변식을 고정한다 | 앞쪽 끼어들기 비용 상한은 재지 않는다 |
| C. 어댑터가 순번을 비오름차순으로 내게 바꿈 | 비 단언이 의미를 가진다 | 계약(순번은 늘기만 한다) 변경이라 T13 범위 밖 |

채택 B. 감독이 수용(PR #56 검토 #1).
대가: 앞쪽 끼어들기 비용은 측정하지 않는다.
다시 볼 조건: 어댑터가 순번을 비오름차순으로 낼 수 있게 되면 비 단언을 되살린다.

## 3. S6 미달 기록 방식
250만 점 규모 구간당 바이트 51.6 MB(문턱 3,000,000 B 의 17.2배, MB = 10^6 B)는 T13 범위 밖(서버·코덱·송출 예산)이다.

| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 이 PR 에서 문턱 단언을 넣고 실패 상태로 둠 | 미달이 CI 에 드러난다 | 병합이 막힌다. 해소는 서버·코덱 변경이라 T13 범위 밖 |
| B. 현재값 회귀 상한(구간당 ≤ 53,000,000 B)을 'S6 통과 단언이 아님' 이라 명시해 단언하고 배율을 출력(채택) | 악화는 막고 미달 사실을 숨기지 않는다. 문턱은 낮추지 않는다 | 회귀 상한이 문턱과 헷갈릴 수 있다(시험 제목·주석에 명시) |
| C. 문턱을 측정값에 맞춰 올림 | 시험이 통과한다 | 성공 기준 완화 — 금지 |

채택 B. 10만 점 합성 시험 제목에도 'SPEC 규모 아님' 을 병기한다. 해소는 T13.B(별도 PR).
대가: 회귀 상한은 문턱보다 17배 느슨한 임시 값이다.
다시 볼 조건: T13.B 에서 large 구간당 ≤ 3,000,000 B 단언을 넣는다. 그때 회귀 상한 시험을 지운다.
