# 0051 T15.5 추적 카메라 감쇠: 지수 감쇠와 기본값

- 상태: 승인(조건부 — F-426 정정)
- 날짜: 2026-10-05
- 결정한 사람: 작업자(제안)
- 관련: TASKS T15.5, contracts/controlview/chase.mjs, 실험 노트 experiments/t15-5.md

## 맥락

관제탑 카메라는 추적 대상(드론)의 위치와 방위를 따라가되, 부드럽게 움직이도록 감쇠를 적용해야 한다. 원본 towerViewer.ts 의 감쇠 방식과 파라미터를 파악하기 위해, [cloud] 에서는 원본을 열 수 없어 기존 감쇠 의미를 대조하지 못했다. 따라서 기본값과 감쇠 공식은 모두 추정(origin 'estimated')이며, T15.0L [local] 과의 비교로 검증이 필요하다.

## 선택지

| 선택지 | 의미 | 장점 | 단점 | 근거 |
|---|---|---|---|---|
| (a) 프레임당 고정 비율 보간 | `p ← p + (target − p)·c`, c 는 프레임마다 상수 | 구현 단순 | 프레임 길이에 의존: dt 가 길면 추적이 지연되거나 반응이 과도함 | 원본 의미 미확인 |
| (b) 지수 감쇠 (선택) | `a = 1 − exp(−dt/tau)`, tau 는 시간 상수(초). 차이를 a 배로 줄임 | 프레임 길이 무관: dt 를 둘로 나눠 두 번 걸어도 한 번과 같음. 물리적 의미 명확(1/e 시간) | 지수 연산 필요(미미한 성능 비용) | 원본이 이 방식이라고 가정 |
| (c) 임계 감쇠 스프링 | 과도 응답 표본: 속도 추정 필요 | 과도 응답 제어 가능 | 파라미터 2개 필요. 원본의 감쇠 의미와 맞지 않음(미확인) | 원본 의미 불명 → 기각 |

## 결정

### 감쇠 공식

**지수 감쇠를 채택한다: `a = 1 − exp(−dt/tau)`, 여기서 tau 는 초 단위 시간 상수.**

감쇠 계수 a 로:
- 위치 각 성분: `p ← p + (target − p)·a`
- 방위(yaw): `yaw ← yaw + wrapPi(targetYaw − yaw)·a`, 여기서 wrapPi 는 방향을 (−π, π] 범위로 접어 최단 호로 보정

방위 ±π 경계를 가로질러도 먼 쪽으로 돌지 않는다.

### 기본값 (추정)

| 파라미터 | 값 | 설명 |
|---|---|---|
| `tauSec` | 0.35 s | 감쇠 시간 상수. 차이가 1/e(≈0.368)로 줄어드는 시간. 0 이면 감쇠 없음(즉시 추적) |
| `distM` | 30 m | 대상 뒤 거리. 카메라 위치 = 대상 − distM·(sin yaw, cos yaw, 0) + (0,0,heightM) |
| `heightM` | 10 m | 대상 위의 높이 |
| `lookAheadM` | 0 m | 시선 향점(카메라가 보는 곳): 대상 + lookAheadM·(sin yaw, cos yaw, 0) |
| `fovYRad` | 0.9 rad | 수직 시야각(라디안) |
| `maxDtSec` | 0.25 s | 한 스텝의 dt 상한. dt ≤ maxDtSec 로 제한하여 매우 낮은 fps(≈4 fps 이하)에서도 과도한 변화 방지 |

모든 기본값은 원본 towerViewer.ts 와 비교 전까지 추정이므로 origin 'estimated' 로 표시된다. T15.0L [local] 에서 검증 예정이다.

### 호출 규칙

**첫 setTarget 은 감쇠 없이:**
`setTarget(pos, yaw)` 의 첫 호출은 즉시 그 위치로 놓고, 이후 호출부터 감쇠를 적용한다. 이는 원점이나 초기 상태에서 대상으로 날아오는 것을 방지한다.

**목표가 없으면 null:**
`camera()` 는 대상이 한 번도 주어지지 않았으면 null 을 돌려준다. 어떤 자세도 지어내지 않으며, 도착한 상태만 그린다.

### renderer_basis 미적용

이 층은 renderer_basis.md 의 렌더링 기준선(좌표, 카메라, 정점 법선)을 따르지만, 추적 카메라의 감쇠 공식 자체는 기준선 밖이다. 이유:
- 감쇠는 관제탑 UI 의 현지 로직(네트워크·타이머 없음)
- 좌표는 GeoAnchor 기준 ENU(x=동, y=북, z=위)로 기준선과 같음
- 카메라 기하(yaw, pitch, fov)는 기준선과 같음

## 근거

### 기존 감쇠 의미 대조 불가

원본 towerViewer.ts 는 [cloud] 에서 열 수 없어, 기존 감쇠가 다음 중 어느 방식인지 확인할 수 없었다:
- 프레임당 고정 비율(프레임 길이 의존) vs. 지수 감쇠(프레임 길이 무관)
- 스칼라 보간 vs. 벡터 보간
- 방위 처리 규칙

따라서 선택지 (b) 의 지수 감쇠와 모든 기본값은 추정이며, T15.0L [local] 과의 비교로 검증된다(decisions/0051 검증 조건).

### dt 상한 근거

감쇠가 프레임 길이에 무관하려면, 아무리 큰 dt 에서도 합리적인 움직임을 보여야 한다. 그러나:
- dt = 1 s(매우 낮은 fps) 이상에서는 보간의 의미가 흐려짐
- 매우 낮은 fps(≈4 fps 이하) 환경에서 극단적인 변화를 제한할 필요가 있음

따라서 **maxDtSec = 0.25 s** 로 제한한다. 일반적인 60 fps(dt ≈ 0.0167 s)에서는 적용되지 않고, 매우 낮은 fps 에서만 변화를 제한하는 역할을 한다.

### 지수 감쇠 선택 근거

지수 감쇠는 물리적 의미가 명확하고(시간 상수), 프레임 길이 변화에 강건하다(프레임 길이 무관 성질). 이는 네트워크 환경에서 dt 가 달라지는 관제탑 UI 에 적합하다.

## 대가

- **시간 상수 추정:** 모든 기본값이 추정이므로, [local] 비교 후 조정이 필요할 수 있음
- **지수 연산 성능:** exp 함수 호출이 필요하나, 매 프레임 1회 정도이므로 성능 영향은 미미함
- **임계 감쇠 미지원:** 과도 응답 제어가 필요하면 tau 값을 조정하거나 시간 상수 2개 방식으로 확장 필요(현재 기각)

## 다시 볼 조건

1. **T15.0L [local] 에서 원본 towerViewer.ts 와 대조:**
   - 감쇠 공식이 정말 지수 감쇠(프레임 길이 무관)인지 확인
   - tauSec, distM, heightM, lookAheadM, maxDtSec 의 원본 값 확인
   - fovYRad 가 정말 0.9 rad 인지 확인

2. **파라미터 조정 필요성:**
   - [local] 에서 실제 추적 거리와 높이로 테스트하여 시각적 만족도 확인
   - tau 값이 0.35 s 에서 너무 느리거나 빠른지 검증

3. **원본이 프레임당 보간이면 변경:**
   - 만약 원본이 지수 감쇠가 아닌 프레임당 고정 비율이라면, 선택지 (a) 로 돌아가 호환성 맞춤
   - 기본값도 함께 조정
