# 0003 클린룸 미적용, 라이선스 선으로 대신한다

- 상태: 승인
- 날짜: 2026-10-01
- 결정한 사람: 사람
- 관련: RULES §4

## 맥락
선행 프로젝트(skylens-stream-lab)는 기존 복원 소프트웨어 소스를 보지 않는 클린룸 규칙을 쓴다. 이 프로젝트에도 적용할지.

## 결정
클린룸은 적용하지 않는다. 기존 오픈소스를 열람·참고해도 된다. 코드를 가져올 때만 라이선스를 본다.

## 근거
- 개발 속도. 렌더링·압축은 공개 구현(three.js, GaussianSplats3D, SPZ 등)에서 배울 것이 많다.
- 대신 라이선스 선을 둔다: MIT·BSD·Apache 는 고지와 함께 차용 가능, AGPL·GPL 계열은 열람만.
- 확인한 라이선스: three.js MIT, GaussianSplats3D MIT, OpenMVS AGPL-3.0 (2026-10-01 GitHub API 로 확인).

## 대가
"독자 구현"을 주장할 근거가 약해진다. 차용 출처 표기를 빠뜨리면 라이선스 위반이 된다(감독 검증 축 8 이 점검).

## 다시 볼 조건
대외 발표·특허 등으로 독자성 입증이 필요해지면 해당 모듈부터 클린룸으로 다시 쓰는 것을 검토한다.
