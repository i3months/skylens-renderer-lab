# 0067 현황판 송출: 대역폭 상한 없음, 원본 점 전부 무손실 송출

- 상태: 제안
- 날짜: 2026-10-07
- 결정한 사람: 사람(2026-10-07, 대역폭 상한 없음·화질 우선), 작업자(구현 제안)
- 관련: TASKS T13.HQ, SPEC §4·§4.1, 결정 0043·0065(대체됨), 실험 노트 [experiments/t13hq.md](../experiments/t13hq.md)
- 결정 0066(다중 시드 기준)은 S6·S9 를 다시 정해 대상이 없어졌으므로 '폐기(대상 없음)' 로 본다(번호 0066 은 관제탑 입력 상수 결정이 쓴다).

## 맥락
이전 안(0043·0065)은 구간당 3 MB 예산 안에서 솎기·배분으로 최소 SSIM 0.7579 를 얻었다. 사람 결정으로 상한을 없애고 화질을 우선한다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| 0065 유지(예산 3 MB, 솎기) | 대역폭 작음 | 최소 SSIM 0.76 |
| 원본 점 전부 + codec 1 무손실 | 최소 SSIM ≥ 0.982, 구현 단순(솎기·배분 제거) | 구간당 약 23.4~24.8 MB(이전의 약 8배) |
| 손실 코덱(S2 안, 취소됨) | 대역폭 절감 | 사람 결정으로 취소 |

## 결정
`S6_SEND_CONFIG = { codec: 1 }`. 솎기·바이트 예산·낮은 수준 보장 없음. S9-현황판 ≥ 0.95 를 시드 1..6 모두 단언한다. 구간당 바이트는 출력만 한다.

## 근거(실측, 구간당 250만 점·flat_boxes·320x180·8시점)
시드 1..6 최소 SSIM 0.9841·0.9851·0.9822·0.9841·0.9846·0.9842(codec 1 위치 양자화로 0.95 미만인 시드 없음, 코덱 변경 없음). levels 장면 구간 바이트 24.82/23.54/23.37 MB, 초기 1.66 MB.

## 대가
SPEC S6 의 3 MB·15 MB 문턱은 이 경로에서 더 이상 만족하지 않는다(사람 결정으로 상한 폐지). server/scheduler/segment_budget 은 제품에서 import 하는 곳이 없어졌다(정리는 감독 판단).

## 다시 볼 조건
실제 망 대역폭 측정(T16 부하)에서 구간 도착이 지연 사다리를 깰 때, 또는 사람이 상한을 다시 정할 때.
