# 0004 [cloud]/[local] 작업 분리

- 상태: 승인
- 날짜: 2026-10-01
- 결정한 사람: 사람
- 관련: TASKS 태그 규칙

## 맥락
자동 루틴은 클라우드 세션에서 돈다. 클라우드 세션에는 GPU 가 없고, GPU 서버는 사람이 포털 로그인을 직접 넣어야 닿는다.

## 결정
모든 작업에 [cloud] 또는 [local] 을 붙인다. 자동 루틴은 [cloud] 만 하고, [local] 은 사람이 띄운 세션에서만 한다. 사람·실기기·GPU 가 있어야만 채울 수 있는 미달은 반려 사유가 아니라 [local] 하위 작업으로 떼어 낸다.

## 근거
- 클라우드 세션 실측: GPU 없음(T02 runtime 노트 §1).
- GPU 서버 경로는 맥 → 파이 → 대전 → 포털 로그인 → 판교이며 클라우드에서 닿지 않는다.
- T01 이 이 미달로 세 번 반려된 뒤 범위를 쪼개 병합됐다(감독 기록 2026-10-01).

## 대가
[local] 작업은 사람이 처리할 때까지 쌓인다. 2단계(A)는 대부분 [local] 이라 자동 진행이 느려진다.

## 다시 볼 조건
GPU 가 있는 클라우드 환경이나 상시 켜 둘 로컬 기계가 생기면 [local] 전담 로컬 작업자를 붙인다.
