# 0002 B 를 먼저 완성한다

- 상태: 승인
- 날짜: 2026-10-01
- 결정한 사람: 사람
- 관련: TASKS 1단계(T01~T17), 2단계(T20~T24)

## 맥락
A 와 B 중 무엇을 먼저 만들지.

## 결정
1단계에서 B 를 두 화면에 적용해 성공 기준을 통과시키고, 2단계에서 현황판 저사양에 A 를 얹는다. 2단계는 1단계 자산 포맷을 입력으로 쓴다.

## 근거
- B 는 A 의 선행 조건이다. 서버 GPU 렌더러도 LOD·컬링된 자산을 입력으로 받아야 한다. 원본(구간당 약 250만 점 × 27 B ≈ 67 MB, renderer_basis.md §7-4)을 매 프레임 훑는 서버 렌더러는 동시 30명을 감당하기 어렵다(추정).
- B 의 작업은 대부분 GPU 없이 클라우드에서 검증할 수 있다(0004). A 의 핵심(GPU 래스터화·인코더)은 [local] 이다.
- B 만으로도 대역폭·첫 프레임 지표가 개선돼 중간 성과가 나온다.

## 대가
현황판 저사양 기기 지원이 2단계까지 늦어진다.

## 다시 볼 조건
1단계가 길어져 저사양 기기 지원이 급해지면 A 를 일부 앞당기는 것을 검토한다.
