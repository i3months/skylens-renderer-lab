# 0027 codec 1(SKLC1): 양자화 값 유지 + 모턴 재배치 + 직접 구현 범위 부호화

- 상태: 제안
- 날짜: 2026-10-03
- 결정한 사람: 작업자(제안)
- 관련: TASKS T09, 실험 노트 experiments/codec.md, 제품 contracts/codec/index.mjs, format/ASSET_FORMAT.md §4.3

## 맥락
T03 이 위치 u16·색 u8·법선 snorm8 양자화(§5)를 이미 고정했다(오차 §8). T09 는 그 위에 압축을 얹어 S6(구간당 3 MB)에 다가가야 한다. 헤더의 codec 필드는 0(무압축)만 정의돼 있었다.

## 선택지
| 선택지 | 장점 | 단점 | 근거 |
|---|---|---|---|
| A. 양자화 값 유지 + 모턴 순 재배치 + 필드별 차분 스트림 + 직접 구현 범위 부호화(채택) | §8 오차 상한이 그대로 성립, 의존성 0, 브라우저에서 순수 JS 로 복호, 주 버전 유지(codec 값 추가는 부 버전 허용 §9) | 직접 구현 코드 책임, 점 순서가 모턴 순으로 바뀜 | 모턴 순 키 차분이 무작위 순 대비 0.539 배(합성 지면 20만 점, T09.4 시험) |
| B. deflate(DecompressionStream·zlib) | 구현 없음 | 브라우저 지원·바이트 형식 의존, 점 단위 스트림 설계와 맞지 않음, 모델 적응 불가 | 명세 §4.1 의 deflate 측정은 SoA 이득만 보임 |
| C. 양자화를 더 거칠게(위치 1 cm 등) | 더 작음 | 주 버전을 올려야 함(§9: 오차 상한을 키우는 변경), 화질 위험 | SPEC 1 cm 상한은 §8 의 2 mm 이하로 이미 충족 |

## 결정
codec 1 은 양자화 값을 바꾸지 않고, 점을 모턴 순으로 재배치해 위치 키 차분(LEB128)·법선 차분(지그재그)·색(차분/하위 2 비트 손실/팔레트)을 필드별 스트림으로 만들고, 각 스트림을 LZMA 방식 적응형 이진 범위 부호화(공개 알고리즘 직접 구현, 라이선스 차용 없음)로 압축한다. 형식 1(27 B 점)만 받는다.
