# 0010 ws_bytes 끊긴 같은 최고 수준 원본은 사본으로 본다

- 상태: 승인
- 날짜: 2026-10-01
- 결정한 사람: 작업자(제안, T01M) → 감독 승인
- 관련: F-053, 제품 bench/baseline/ws_bytes/index.mjs 머리 주석, 연구 experiments/baseline-fixes-7.md

## 결정
같은 구간에서 원본 최고 수준과 같은 수준의 원본 프레임이 분할 연속이 끊긴 뒤(resend 나 다른 수준 프레임이 끼어든 뒤)에 오면 늦게 온 사본으로 본다. 그 프레임과 뒤따르는 같은 수준 조각·final 은 모두 stale 이고, 완결 판정과 segments 합은 stale 아닌 원본이라는 같은 프레임 집합을 근거로 한다.

## 근거
- 분할 전송은 같은 수준 연속 프레임이다. 기존 규칙도 resend 뒤 같은 수준 원본 바이트를 stale 로 셌다.
- 딜레이 패턴은 수준을 교체하므로 (구간, 수준)마다 원본은 한 번이다. 새 메시지로 보면 같은 수준을 두 번 더한다.
- 도착하지 않은 것을 메우지 않는다. 바이트를 세지 않는 사본의 final 로 원본이 끝났다고 채우지 않는다.

## 대가
- 완결이 도착 순서에 의존한다: [L2 5, rL2 5, L2 5 final] 미완, [L2 5 final, rL2 5, L2 5] 완결 [5]. 추월된 낮은 수준이 끼는 [L2 5, L1 3, L2 5 final] 도 미완이다.
- "(구간, 수준)마다 원본은 한 번" 은 skylens 송신 코드와 대조하지 않은 가정이다(F-057 ⑤).

## 다시 볼 조건
- 실제 skylens 송신 코드나 녹화에서 한 (구간, 수준)에 원본 메시지가 둘 이상 오는 경우가 확인되면 새 메시지 규칙으로 바꾼다.
