# 0024 퇴화 시점에 래스터 해상도 조건(정수·MAX_PIXELS)을 넣고, 모든 컬링 단계가 isDegenerateView 하나를 쓴다

- 상태: 승인
- 날짜: 2026-10-03
- 결정한 사람: 감독
- 관련: TASKS T08.F19, FEEDBACK F-120·F-132, 제품 PR #23(e1d2ef4), 연구 experiment/degenerate-unify 의 experiments/degenerate_unify.md, 결정 0023 보완

## 맥락
PR #22 검토에서 8193×8193 카메라가 isDegenerateView 로는 정상인데 결합 경로는 'cull:' 오류로 던지고, 단계마다 퇴화 판정 식이 달라 같은 카메라에 결과가 갈렸다(F-120). 0023 은 퇴화 조건을 'NaN·Infinity·해상도/초점 ≤ 0·R 비회전·시야각 1e-6 rad 미만·변당 1e6 px' 로만 적었다.

## 선택지
| 선택지 | 장점 | 단점 | 근거 |
|---|---|---|---|
| A. 해상도 비정수·픽셀 수 > 2^26 은 계속 'cull:' 오류 | 잘못된 입력이 드러남 | 단계마다 던짐/빈 결과가 갈림, 판정 함수와 실제 경로 불일치 | F-120 재현 |
| B. 이 조건도 퇴화로 보고 빈 결과(채택) | 판정 하나로 모든 단계가 같은 결과, 던지지 않음 계약과 맞음 | 잘못된 해상도가 오류 대신 빈 화면이 됨 | PR #23 시험·감독 대조 |

## 결정
래스터 조건(정수 해상도, width×height ≤ MAX_PIXELS = 2^26)을 퇴화 조건에 넣고, frustum·backface·occlusion·distance·predict·priority·combine 기본 판정과 클라이언트 복제본이 같은 식을 쓴다.

## 근거
PR #23(e1d2ef4) 감독 검토: 서버·클라이언트 판정 무작위 20만 개 불일치 0(축 1a), 구·신 정상 카메라 700개 단계별 출력 불일치 0(축 1b), npm test 1744 중 1732 통과·0 실패·12 건너뜀(감독 직접).

## 대가
비정수·과대 해상도를 넣은 호출자는 오류 대신 빈 결과를 받는다. 카메라 '구조' 오류(필드 누락·타입 배열·문자열)는 아직 단계마다 던짐/빈 결과가 갈린다(F-132 에서 정리).

## 다시 볼 조건
실제 클라이언트에서 빈 결과가 원인 불명의 빈 화면으로 보고되면, 퇴화 원인 코드를 결과에 함께 돌려주는 방식을 검토한다.
