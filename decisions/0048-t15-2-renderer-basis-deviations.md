# 0048 T15.2 드레이프 그리기: renderer_basis 에서 벗어난 세 이탈

- 상태: 제안
- 날짜: 2026-10-05
- 결정한 사람: 작업자(제안)
- 관련: TASKS T15.2(드레이프 그리기), FEEDBACK F-402·F-403·F-404, 결정 0044·0046, 제품 contracts/controlview/drape.mjs·client/tower/drape/sample.mjs·server/terrain/drape/index.mjs

## 맥락

T15.2 드레이프 그리기(위성 영상을 지형 타일 위에 입힌다)는 renderer_basis.md 에 명시되지 않은 세 가지 이탈을 가진다.

1. 표본점이 속한 화소의 mask = 0 일 때 처리(mask 0 칸 → null, mask>0 이웃 재정규화가 메우기가 아닌 이유)
2. mask 1..254 의 가중치 처리(동등 가중, mask/255 를 곱하지 않는 근거)
3. 위성 색에 지형 음영 비율 곱하기(음영 비율 곱의 이유와 대가)

이들을 이탈로 명시하고 각각의 근거와 대가를 기록한다.

## 이탈 1: 표본점이 속한 화소 칸의 mask = 0 이면 null, mask>0 이웃만 가중 재정규화

**규칙(sample.mjs:3-6)**:
- (a) 표본점이 속한 화소 칸(i = clamp(floor((x−minX)/(64/width))), j = clamp(floor((maxY−y)/(64/height))))의 mask 가 0 이면 null.
- (b) 그 칸의 mask 가 0 보다 크면 4이웃 이중선형 보간하되 mask>0 인 이웃만 가중하고 남은 가중으로 재정규화.

**근거(renderer_basis 벗어남)**:
renderer_basis 는 위성 영상 표본을 명시하지 않는다. 이 규칙의 (a) 는 위성 영상에 데이터가 없는 화소(mask = 0, 즉 영상 밖)를 메우지 않고 지형 색을 그대로 둔다. (b) 는 부분 피복 화소(mask < 255)에서 데이터 있는 이웃으로만 보간하여, 실제 데이터만 기여하게 한다.

**대가(menus·비용)**:
- (a) mask = 0 화소 위의 이웃이 모두 mask > 0 이어도 지형 색을 그대로 두므로, 영상 경계 근처에서 시각적 불연속이 생길 수 있다.
- (b) 이웃 재정규화로 인해 이웃 가중의 합이 입력한 가중(보간 계수)과 달라질 수 있지만, 실제 데이터가 있는 이웃만 보간하므로 외삽을 피한다.

---

## 이탈 2: mask 1..254 는 255 와 같은 색 동등 가중(mask/255 를 곱하지 않음)

**규칙(sample.mjs:5, drape.mjs:7)**:
mask 1..254 는 255 와 같은 가중으로 처리한다. 즉, 부분 피복(mask < 255)인 화소의 색을 그대로 쓰고, 피복 비율(mask/255)을 색에 곱하지 않는다.

**근거**:
- mask 는 영상에서 실제로 덮인 면적 비를 저장한다(index.mjs:127, f >= 1 - FULL_EPS 이면 255, 아니면 Math.round(255·f)).
- mask < 255 는 부분 피복을 나타내지만, 그 부분만 덮인 화소의 색은 이미 덮인 부분의 평균이다(index.mjs:121-127, 덮인 부분만으로 평균).
- 따라서 색에 다시 mask/255 를 곱하면 피복 면적이 두 번 반영되어 지나치게 어두워진다.

**대가**:
- 부분 피복 화소(mask < 255)의 색이 완전 피복(mask = 255)과 같은 무게로 보간에 기여한다. layer.apply 에서는 지형 색과 섞지 않고 위성 색으로 완전히 교체하므로(drape.mjs:5), 부분 피복 화소의 무게가 지형 색에 영향을 주지는 않는다. 그러나 표본 단계에서 mask 값이 색 밝기에 직접 영향을 주지 않는 것이 의도인지는 명시되어야 한다.

---

## 이탈 3: 위성 색에 지형 음영 비율을 곱하기

**규칙(drape.mjs:13, shade.mjs:1-2, index.mjs 에서 호출)**:
드레이프 층을 만들 때 opts.shade 를 true(기본값)로 설정하면, 위성 색에 지형 음영 비율(terrainRgb 채널 평균 ÷ baseRgb 채널 평균)을 곱한다. 이를 통해 지형의 명암 정보를 위성 색에 반영한다.

**근거(renderer_basis 벗어남, decision 0046 기준)**:
- 지형 렌더링은 정점 법선 보간 Lambert 음영을 포함한다(결정 0046, contracts/controlview/terrain.mjs:18). 드레이프는 이를 추가 음영 비율로 보정한다.
- 위성 영상은 실제 태양 조명을 받은 영상이므로 색에 조명 정보가 담겨 있을 수 있지만, 같은 시점과 해석도에서 재샘플링되므로 지형 법선을 직접 반영하지 않는다.
- 음영 비율(terrainRgb 채널 평균 ÷ baseRgb 채널 평균)을 곱함으로써 지형의 기하 기반 음영(높이·경사·법선, 정점 법선 보간)을 보존하여 3D 입체감을 유지한다.

**대가**:
- 이중 음영 가능성: 위성 영상에 이미 태양 음영이 있다면, 지형 음영을 추가로 곱하면 일부 영역이 과도하게 어두워질 수 있다. 이를 완화하기 위해 opts.shade = false 로 비활성화할 수 있다.
- 계산 비용: 프레임당 화소마다 음영 비율을 계산하거나(음영 표로 최적화) 기준색의 음영 테이블을 미리 만들어야 한다. 성능 측정(experiments/t15-2.md F-403 ③): 벤치 1280×720 전 화소 적중에서 참조 경로 520~535 ms 대비 새 경로(드레이프 전체) 70 ms 로 비율 0.130~0.136 이다. **음영 비율 계산 단독의 비용은 측정하지 않았다(드레이프 전체 경로와 참조 경로의 비교).**

## 결정

위 세 이탈을 renderer_basis 로부터의 편차로 명시하고, 각각의 근거와 대가를 기록한다. 구현은 contracts/controlview/drape.mjs, client/tower/drape/sample.mjs, client/tower/drape/shade.mjs, server/terrain/drape/index.mjs 에 이미 반영되어 있다. T15.2 의 선행 조건으로 이 이탈들이 정당화됨을 확인한다.

---

## 근거

제품 코드 검토 및 이 저장소 experiments/t15-2.md 의 F-402·F-403 항목.

- **이탈 1 (a)**: client/tower/drape/sample.mjs:48 에서 표본점이 속한 화소 칸의 mask 가 0 이면 null 을 반환한다. drape.mjs:5 계약에 "타일이 없거나 표본점이 속한 화소 칸의 coverage.mask 가 0 인 곳은 지형 색을 그대로 둔다(이웃 색으로 메우지·꾸미지 않는다)"고 명시된다.
- **이탈 1 (b)**: sample.mjs:54-65 에서 mask > 0 이웃만 가중해 재정규화한다. 가중 합이 0 이면 null 을 반환하여 메우지 않는다(line 63).
- **이탈 2**: sample.mjs:5-6 주석에 "mask 1..254 는 255 와 같은 가중(색 동등 가중, mask/255 를 곱하지 않는다)"고 명시한다. server/terrain/drape/index.mjs:127 에서 mask 를 계산할 때 이미 덮인 부분만 평균하므로(121-127), 색에 다시 mask/255 를 곱하면 중복이다.
- **이탈 3**: contracts/controlview/drape.mjs:13 에서 opts.shade 기본값은 true 다(지형 음영 비율을 곱함). client/tower/drape/shade.mjs:1-2·16-47 에서 음영 비율을 정의하고(terrainRgb 채널 평균 ÷ baseRgb 채널 평균), index.mjs:78·111 에서 useShade 옵션을 확인해 프레임당 한 번 음영 표(shadeLut)를 만든 뒤 화소 루프에서 적용한다. 이탈 이유는 위성 영상이 지형의 정점 법선을 직접 반영하지 않기 때문에, 지형 렌더링의 Lambert 음영(결정 0046)을 보정하려면 음영 비율을 추가로 곱해야 한다는 것이다(line 52-56).

## 대가

이탈 1 (a):
- 영상 경계 근처에서 지형 색과 위성 색의 불연속이 보인다.

이탈 1 (b):
- 이웃 가중의 합 w 가 0 이면(모든 이웃이 mask = 0) null 을 반환한다(sample.mjs:63). 그렇지 않으면 재정규화된 가중으로 보간하므로, 남은 이웃만 기여하여 외삽을 피한다.

이탈 2:
- 현재 layer.apply 에서는 지형 색과 섞지 않고 위성 색으로 완전히 교체한다(drape.mjs:5). 따라서 표본 단계에서 mask 값이 색 밝기에 직접 영향을 주지 않는다. 그러나 나중에 layer.apply 가 지형 색과 섞는 방식을 바꾸면(부분적 투명도 등), mask < 255 화소의 동등 가중 처리를 다시 검토해야 한다.

이탈 3:
- 이중 음영 가능성: 위성 영상에 태양 음영이 있다면 과도하게 어두워질 수 있다. opts.shade = false 로 비활성화할 수 있다.
- 계산 비용: 프레임당 음영 계산 추가. 최적화로 음영 비율 표(shadeLut, client/tower/drape/shade.mjs:103-130)를 미리 만들어 조회로 줄인다. 성능 측정(experiments/t15-2.md F-403 ③)의 참조 대 새 경로 비율 0.130~0.136(음영 포함 전체 드레이프 경로)은 음영 비율 단독 비용을 나타내지 않는다.
